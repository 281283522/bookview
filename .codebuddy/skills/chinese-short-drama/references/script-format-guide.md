# 剧本格式写作指南

## 剧本基本结构

### 场景标题（Scene Heading）
每场戏必须以场景标题开头，包含三个要素：内景/外景、地点、时间。

```
### 场景1：林雨的办公室
- 时间：白天
- 地点：市公安局刑警队办公室
- 人物：林雨、王强
```

| 时间标记 | 说明 |
|---------|------|
| 清晨 | 5:00-8:00 |
| 白天 | 8:00-17:00 |
| 黄昏 | 17:00-19:00 |
| 夜晚 | 19:00-24:00 |
| 深夜 | 0:00-5:00 |

### 场景描述
简洁明了的环境描写，**不超过3行**。只写拍摄需要的内容。

**太长：**
> 这是一间普通的办公室，墙上挂着锦旗和奖状，桌上有文件、电脑、水杯、照片、笔筒、台历、一盆绿萝。窗帘半拉着，阳光从缝隙里透进来，在地板上形成一道光带。

**OK：**
> 刑警队办公室，墙上挂满锦旗。窗帘半拉，阳光在地板上画出一道斜线。

### 角色对话
格式：`[角色名]：[对话内容]`

**原则：**
- 对话长度不超过3行（屏幕显示量）
- 不要写潜台词，演员会用表演表达
- 每句对话后，考虑是否需要一个反应或动作

### 动作描述
只写观众**能看到的**内容。不要写角色的内心想法。

**不要写：**
> 林雨心里很紧张，但她强装镇定。

**要写：**
> 林雨端起水杯，手在轻微颤抖。她喝了一口，把杯子放下，杯底磕在桌上发出一声响。

## 镜头感写作技巧

### 用动作取代对话
**对话过多：**
> 林雨："你害怕吗？"
> 王强："不害怕。"
> 林雨："真的？"
> 王强："真的。"

**用动作表达：**
> 王强点燃一支烟，手在打火机上按了三次才打着。他深吸一口，缓缓吐出烟雾。
> 林雨盯着他，没有说话。

### 视觉信息优先
能用画面交代的，不用台词交代。

> （不需要说"外面下着大雨"）
> ——王强走进来，身上湿透，头发贴在额头上，地上留下一串湿脚印。

## 每集剧本字数参考

| 时长 | 场景数 | 总字数参考 |
|-----|-------|-----------|
| 5-10分钟 | 2-3个 | 1500-2500字 |
| 10-15分钟 | 3-4个 | 2500-3500字 |
| 15-20分钟 | 4-5个 | 3500-5000字 |
| 20-30分钟 | 5-7个 | 5000-7000字 |

## 拍摄可行性自检清单

- [ ] 场景数量是否在预算范围内？（极简1-2个，简单3-4个，中等5-6个）
- [ ] 是否有需要特效的场景？能否简化或替代？
- [ ] 是否有户外夜景场景？光线问题能否解决？
- [ ] 每个场景的到场角色是否都合理？
- [ ] 群演数量是否可控？（能不用的就不用）
- [ ] 道具是否都是日常常见物品？
- [ ] 角色服装是否需要特殊定制？
- [ ] 每个动作描述是否都具体可拍？
