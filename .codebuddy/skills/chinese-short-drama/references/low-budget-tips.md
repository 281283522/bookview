# 小成本拍摄技巧指南

## 场景改造技巧

### 一个场景拍出多个感觉
利用简单的道具改变，把同一个物理空间拍出不同场景的感觉：

| 实际空间 | 简单改造 | 拍出来像 |
|---------|---------|---------|
| 客厅 | 挂上白布+台灯 | 审讯室/会议室 |
| 卧室 | 把床位贴墙+蓝布 | 医院病房 |
| 厨房 | 关灯+手电筒 | 案发现场/地下室 |
| 阳台/天台 | 对角线构图 | 楼顶对峙场景 |
| 楼道 | 从上往下拍 | 幽闭空间/逃亡 |
| 浴室 | 水汽+逆光 | 悬疑/梦境氛围 |

### 低成本场景替代方案

| 你想要拍 | 可以用 |
|---------|-------|
| 警局办公室 | 普通办公室+警服+文件 |
| 医院急诊室 | 白色房间+白大褂+医疗道具 |
| 停车场追逐 | 夜晚地下车库（光线可控） |
| 咖啡厅对话 | 家里的餐桌+咖啡杯 |
| 车里对话 | 停在路边的真实车辆 |
| 案发现场 | 空旷房间+警戒胶带 |

## 灯光技巧

### 没有专业灯光怎么办？
- **白天拍摄**：利用自然光，窗边是最好的光源
- **阴天拍摄**：扩散光最柔和，适合情感戏
- **从窗户打光**：把台灯放在窗外，制造月光效果
- **手电筒**：拍悬疑场景时的最佳光源工具
- **手机屏幕**：最自然的补光工具

## 音效建议

### 低成本获取好音效
- **环境音**：用手机录一段现场环境音（30秒即可）
- **脚步声**：在不同地面（水泥、木地板、沙子）上走几步录制
- **关门声**：不同材质的门声音不同，多录几种
- **雨声**：用花洒喷水到铁皮上录制
- **风声**：对着麦克风吹气，用衣服摩擦
- **免费音效库**：Freesound.org、Mixkit.co

## 拍摄技巧

### 手机拍摄要点
- **横屏拍摄**：永远不要竖屏
- **双手握持**：保持画面稳定
- **多用固定镜头**：比移动镜头更容易拍好
- **避开逆光**：让人物面向光源
- **收音最重要**：外接一个几十元的领夹麦比画质提升更明显

### 规避常见的"廉价感"
| 问题 | 解决方案 |
|-----|---------|
| 画面晃动 | 用三脚架或靠在墙上固定 |
| 收音差 | 领夹麦+安静环境 |
| 穿帮 | 检查镜面和玻璃反射 |
| 光线不均 | 多角度检查阴影 |
| 表演尴尬 | 多拍几条，选最自然的 |

### 通用基础道具
- [ ] 手机（现场静音）
- [ ] 水杯/饮料瓶
- [ ] 纸张/笔
- [ ] 背包/手提包
- [ ] 钥匙

### 悬疑类特需道具
- [ ] 手电筒
- [ ] 警戒胶带（黄/红）
- [ ] 手套（白/黑）
- [ ] 一次性鞋套
- [ ] 放大镜
- [ ] 文件夹/档案袋
- [ ] 对讲机

### 避免使用的道具
- ❌ 仿真枪械（法律风险）
- ❌ 管制刀具（用其他物品替代）
- ❌ 易燃易爆品
- ❌ 难以清理的物品（假血等，可用番茄酱代替）
