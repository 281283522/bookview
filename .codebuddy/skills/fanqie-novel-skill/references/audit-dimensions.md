# 审计维度（番茄专用版）

> 融合核心创作维度 + 番茄专用检查
> v2.0.1新增：维度30-33（战斗/对话/话疗/循环）

## 严重程度模型

- **critical** — 破坏核心逻辑/连续性/主角锁定/平台红线
- **major** — 明显削弱章节或损害铺垫/回报
- **minor** — 风格、清晰度、重复、局部节奏
- **note** — 可选改进或观察

## 最小审计集（8项强制）

每章写完后**必须执行**以下8项检查，不可跳过：

### 检查1：字数检查
目标：2000-2500字（可根据book_rules.md调整）

### 检查2：AI去味检查（智能替换）
步骤：
1. 搜索禁用词（不禁、竟然、居然、仿佛、宛如、深邃、命运、瞳孔收缩、嘴角上扬）
2. 分析语境（是否在对话中？是否必要？）
3. 智能替换（见ai-detox-guide.md替换表）
4. 语义完整性验证

### 检查3：因果链检查（维度29）
检查每个场景转换是否有因果连接，主角行为是否有动机支撑。

### 检查4：行为-规则一致性检查（维度28）
检查本章是否声明了规则，主角行为是否违反规则。

### 检查5：时间线检查
检查时间跳跃是否交代了中间发生了什么，是否存在"时间黑洞"。

### 检查6：战斗场景检查（维度30）
检查是否有实质性攻击/防御动作（至少3次），是否通过话疗解决。

### 检查7：对话占比检查（维度31）
计算对话占比 = 对话行数 / 总行数，标准：≤25%优秀，>40%超标。

### 检查8：话疗模式检查（维度32）
BOSS级敌人禁止通过对话解决，精英需铺垫3章+。

### 检查9：循环模式检查（维度33，每5章执行）
检测章节结构相似度，检测循环模式重复。

## 审计输出格式

```markdown
# 第X章审计报告

## 最小审计集（8项强制）

| 检查项 | 结果 | 详情 |
|--------|------|------|
| 字数检查 | ✅/⚠️/❌ | 实际字数：{{words}} |
| AI去味检查 | ✅/❌ | 发现{{count}}处 |
| 因果链检查 | ✅/❌ | {{causal_detail}} |
| 行为-规则一致性 | ✅/❌ | {{rule_detail}} |
| 时间线检查 | ✅/❌ | {{time_detail}} |
| 战斗场景检查 | ✅/⚠️/❌/N/A | {{battle_detail}} |
| 对话占比检查 | ✅/⚠️/❌ | 占比：{{ratio}}% |
| 话疗模式检查 | ✅/❌ | {{talk_therapy_detail}} |

## 综合评级
- 评级：✅通过 / ⚠️需小改 / ❌需大改

## 必改项
- ...
```

## 执行频率

| 审计类型 | 频率 | 维度 |
|---------|------|------|
| 最小审计集（8项） | 每章强制 | 8项 |
| 循环模式检查 | 每5章 | 维度33 |
| 完整审计 | 每10章 | 33维度 |
| 生死线检查 | 前三章 | 维度25 |
