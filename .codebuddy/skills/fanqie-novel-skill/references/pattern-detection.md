# 循环模式检测

> 核心目标：检测并防止叙事模式无变化重复

## 一、核心循环模式

### 模式A："觉醒-升级-新敌人"循环
遇到新敌人 → 发现力量不足 → 觉醒新能力 → 击败敌人 → 遇到更强的敌人 → 重复

### 模式B："敌人有苦衷"循环
遇到敌人 → 战斗/对峙 → 发现敌人有苦衷 → 通过对话/共鸣解决 → 敌人加入主角 → 重复

### 模式C："探索新世界"循环
进入新区域 → 发现新规则 → 快速通过 → 到达目标 → 重复

---

## 二、循环模式检测方法

### 章节结构特征提取

每章提取以下特征：
- **开头特征**：第一段类型（对话/描写/动作），前100字关键词
- **主体特征**：主要场景数量，主要活动类型，对话占比区间，是否有战斗
- **结尾特征**：最后一段类型，是否有悬念，冲突是否解决
- **解决方式**：战斗解决/对话解决/话疗解决/融合/逃避

### 相似度计算

```
相似度 = 相同特征数 / 总特征数 * 100%
章节A：[对话开头, 探索主体, 悬念结尾, 话疗解决]
章节B：[对话开头, 探索主体, 悬念结尾, 话疗解决]
相似度 = 100% → 🔴 完全重复
```

## 三、预警规则

| 触发条件 | 预警级别 | 说明 |
|---------|:---:|------|
| 同模式出现2次 | ⚠️ 提醒 | 需注意变化 |
| 同模式出现3次 | 🔴 报警 | 必须变化 |
| 连续3章结构相似度>70% | 🔴 报警 | 章节结构重复 |
| 话疗解决占比>30% | 🔴 报警 | 话疗模式泛滥 |

---

## 四、打破循环的方法

**方法1：插入意外**
标准循环：遇敌→苦衷→话疗→解决
打破：遇敌→苦衷→话疗失败→必须战斗→代价惨重

**方法2：改变解决方式**
上次：话疗解决 → 这次：战斗解决 → 下次：智取解决

**方法3：改变敌人类型**
上次：被操控的敌人（可话疗）
这次：无意识的怪物（必须战斗）
下次：有逻辑的智者（智取）

**方法4：改变代价**
上次：无损 → 这次：受伤 → 下次：牺牲队友

## 五、高潮章专项检测

### 高潮章定义（满足任一）
- 标题含"决战/最终/高潮/击杀"等关键词
- outline.md标记为"高潮章"
- 本章出现BOSS级敌人
- 卷末章节

### 高潮章质量标准

| 检查项 | 标准 | 不合格案例 |
|-------|------|---------|
| 战斗描写 | ≥3次攻击动作 | 决战章：0次攻击 |
| 解决方式 | 战斗/智取 | 决战章：话疗解决 |
| 代价 | 有代价 | 最终章：主角无损 |
| 反转 | 有意外 | 多数无反转 |
