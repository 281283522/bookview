# 商业审查指南

## 一、生死线检查（前三章必查）

### 前300字
- [ ] 主角是否出场？
- [ ] 是否有核心事件？
- [ ] 是否能引起读者好奇心？

### 前1000字
- [ ] 主角身份是否明确？
- [ ] 金手指/特殊能力是否展示？
- [ ] 核心冲突是否建立？

### 第一章末
- [ ] 是否有钩子？（悬念/反转/危机）
- [ ] 读者是否有"想看下一章"的冲动？

### 前三章
- [ ] 核心能力是否展示？
- [ ] 主线目标是否明确？
- [ ] 是否有足够的悬念吸引读者？

---

## 二、商业性检查（每章）

- [ ] 本章是否推进了主线剧情？
- [ ] 章末是否有钩子？
- [ ] 信息密度是否足够？
- [ ] 是否有爽点释放？
- [ ] 是否有新的悬念/伏笔？
- [ ] 读者是否有追更欲望？

---

## 三、付费转化检查

### 付费节点前的准备
- [ ] 当前剧情是否到达高潮？
- [ ] 付费章节前是否有足够的钩子？
- [ ] 读者是否有"不得不付费"的冲动？

### 付费章节质量
- [ ] 付费章是否有实质性内容？
- [ ] 付费章是否对得起读者期待？
- [ ] 付费章后是否有延续的悬念？

---

## 四、完读率优化

### 节奏控制
- 段落要短：多数段落不超过3行
- 对话要多：对话比描写更容易阅读
- 悬念要密：每500字至少一个小悬念

### 注水检查
- [ ] 是否有大段无关环境描写？
- [ ] 是否有大段回忆/科普？
- [ ] 是否有重复的心理描写？
- [ ] 是否有拖节奏的支线？

### 追更率优化
- 章末钩子要足够强
- 避免在平淡处断章
- 每章结尾都要有"未完待续"的冲动
