# 战斗场景指南

> 核心目标：杜绝"话疗"解决BOSS，确保战斗有张力

## 一、实战教训

### Anti-pattern 1：标题承诺"决战"，实际无战斗

标题含"决战"，整章无战斗，全是对话说服。

### Anti-pattern 2：BOSS被"共鸣"唤醒后自我崩解

通过"我们不是来消灭你的，是来解放你的"一句话让BOSS自我崩解。

### Anti-pattern 3：最终BOSS被"融合"而非击败

"它不再是威胁了，它成为了我的一部分"——融合代替战斗。

---

## 二、战斗场景强制规则

### BOSS战铁律

**规则1：BOSS禁止被话疗解决**

❌ 禁止模式：
- "我理解你" → BOSS放弃
- "共鸣/唤醒" → BOSS自我崩解
- "融入/共存" → 冲突消失

✅ 正确模式：
- 发现BOSS逻辑漏洞 → 利用漏洞击败
- 找到BOSS弱点 → 付出代价攻击弱点
- 策略博弈 → 以弱胜强

**规则2：战斗必须有代价**

代价类型（至少选一）：
- 身体代价：受伤、残废、寿命损耗
- 资源代价：消耗关键道具、消耗力量储备
- 情感代价：牺牲队友、牺牲机会

**规则3：战斗必须有战术**

❌ 禁止：纯力量对轰、突然觉醒新力量反杀
✅ 正确：分析敌人规则/能力 → 找到破绽 → 设计战术组合 → 临场调整

### 战斗描写要素

- **攻击动作**：至少3次，类型要多样化
- **防御/闪避**：至少2次，体现战斗的互动性
- **节奏变化**：开局试探 → 发现劣势 → 调整策略 → 反击 → 决胜
- **意象丰富**：避免高频重复"金色光芒""暗红色触手"等

## 三、战斗场景检查清单

### 写前
- [ ] 确认敌人类型（普通/精英/BOSS）
- [ ] 确认敌人能力/规则
- [ ] 设计敌人弱点
- [ ] 规划战斗流程
- [ ] 确定代价

### 写中
- [ ] 攻击动作≥3次？
- [ ] 防御/闪避≥2次？
- [ ] 有战术博弈？
- [ ] 节奏有变化？

### 写后
- [ ] 是否通过话疗解决？→ 🔴 禁止！
- [ ] 是否有代价？
- [ ] 战斗意象是否重复？
- [ ] BOSS是否有尊严？
