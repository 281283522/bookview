# AI去味指南

## 核心原则

AI去味的目标是**智能替换而非机械删除**。保留语义完整性，去除AI痕迹。

---

## 番茄AI味高频禁用词

| 禁用词 | 替换建议 | 说明 |
|--------|---------|------|
| 不禁 | 替换为具体动作或直接删掉 | "他忍不住"→"他握紧拳头" |
| 竟然/居然 | 直接删掉，用上下文体现意外 | "他居然来了"→"他来了"（通过周围反应体现意外） |
| 仿佛/宛如 | 替换为"像""跟...一样"或直接描写 | "仿佛看到了"→"看到了" |
| 深邃 | 替换为具体的颜色或特征 | "深邃的眼睛"→"黑眼睛" |
| 命运 | 替换为具体的人和事 | "命运的捉弄"→直接写发生了什么 |
| 瞳孔收缩 | 替换为更具体的微表情 | "他的瞳孔收缩"→"他眯起眼睛" |
| 嘴角上扬 | 替换为具体的表情 | "嘴角上扬"→"笑了一下" |
| 冰冷 | 替换为具体感受 | "冰冷的眼神"→"他的目光没有温度" |

---

## 检查清单

每章完成后检查：

- [ ] 是否有排比三连？（"他感受到了...他听到了...他看到了..."）
- [ ] 是否有空洞抒情？（"啊，这就是命运啊"）
- [ ] 是否有万能过渡句？（"就在这时""突然""与此同时"）
- [ ] 是否有万能形容词？（"冰冷""深邃""璀璨"）
- [ ] 是否有情感标签？（"他感到很愤怒" → "他把杯子摔在地上"）
- [ ] 是否所有角色说话风格都不同？
- [ ] 是否有超过3个连续相似长度的段落？
