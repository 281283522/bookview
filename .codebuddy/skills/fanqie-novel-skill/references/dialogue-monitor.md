# 对话占比监控

## 计算方法

```
对话行数 = 统计含引号的行数
总行数 = 章节总行数（排除空行）
对话占比 = 对话行数 / 总行数
```

## 标准

| 评级 | 占比范围 | 说明 |
|:---:|:-------:|------|
| ✅ 优秀 | ≤ 25% | 氛围/叙事为主 |
| ✅ 良好 | 26-35% | 平衡得当 |
| ⚠️ 偏高 | 36-40% | 需关注，下章注意控制 |
| 🔴 超标 | > 40% | 必须压缩对话，补充叙事 |

## 趋势监控

- 记录每章对话占比
- 连续3章占比上升 → ⚠️ 预警
- 占比 > 50% → 🔴 立即报警

## 章节类型差异

| 章节类型 | 建议对话占比上限 |
|---------|:--------------:|
| 战斗章 | 30% |
| 探索章 | 35% |
| 对话章（剧情交代） | 45%（需审查是否有注水） |
| 决战章 | 30% |
