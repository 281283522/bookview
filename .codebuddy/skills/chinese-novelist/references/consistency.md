# 连贯性检查清单

每章完成后，逐项检查以下内容：

## 一、人物一致性

### 性格一致性
- [ ] 角色行为是否符合其核心性格设定？
  - 热血正义的角色不会在关键时刻退缩
  - 冷静智慧的角色不会突然冲动行事
- [ ] 如果角色做出"反性格"行为，是否有充分理由？
  - 须在文中明确交代动机或铺垫

### 能力一致性
- [ ] 角色能力是否忽强忽弱？
  - 林雨上一章能徒手制服歹徒，这章不能连门都踹不开
- [ ] 角色专业知识的增减是否合理？

### 关系一致性
- [ ] 角色之间的称呼是否统一？
- [ ] 角色关系的亲疏程度是否前后一致？
- [ ] 已知信息是否被"忘记"？
  - 不要出现A告诉过B的信息，B下一章却不知道

### 细节连续性
- [ ] 角色外貌/衣着是否有变化？（换季节、受伤等需说明）
- [ ] 角色的习惯/口头禅是否一致？
- [ ] 角色伤痕/道具是否连续？（受的伤不会下一章凭空消失）

## 二、情节连贯性

### 时间线
- [ ] 时间推移是否合理？
  - 一天之内能做到多少事，是否符合现实
- [ ] 各章节时间顺序是否正确？
- [ ] 是否有时间矛盾？
  - 如果A地在30分钟车程外，角色不可能5分钟赶到

### 因果关系
- [ ] 情节推进是"因为所以"还是"然后然后"？
  - 正确：A线索→推理→B线索→找到嫌疑人
  - 错误：A线索→找到嫌疑人（跳跃，逻辑缺失）
- [ ] 每个发现是否有前提依据？
  - 角色如何知道要去查这个？必须有合理动机

### 伏笔回收
- [ ] 前文埋下的伏笔是否在本章回收或提及？
- [ ] 若暂时不回收，是否有明确交代"待后续"？
  - 可用"林雨把这条信息记在心上"来标记

### 信息一致性
- [ ] 人物姓名/职业/背景信息是否与设定档案一致？
- [ ] 地点名称和空间关系是否一致？
  - 比如警察局在城东，不会突然变成城西
- [ ] 案件编号、日期、时间等细节是否正确？

## 三、节奏控制

### 章节节奏
- [ ] 本章是否有一个明确的"起承转合"？
  - 起：开头钩子
  - 承：推进剧情/调查/对话
  - 转：冲突升级/新发现
  - 合：结尾钩子

### 悬念密度
- [ ] 是否连续多章都在"调查而没有新进展"？
  - 如果连续3章都是"查到一点线索又断了"，需要调整节奏
- [ ] 是否信息量过大？
  - 一章不要同时揭露三个以上的重大秘密

### 张弛有度
- [ ] 紧张场面之后是否有缓冲段落？
  - 枪战之后不要马上又追车，给角色（和读者）喘息空间
- [ ] 是否过长地停留在平和场景？
  - 超过3页的平和对话/日常描写需要插入冲突或伏笔

## 四、语言风格一致性

- [ ] 叙述视角是否统一？
  - 不要从林雨视角突然跳到凶手的内心想法
- [ ] 全书的语言风格是否一致？
  - 悬疑小说的语言节奏和言情小说是不一样的
- [ ] 专业术语的使用是否准确？
  - 涉及法律、医学、警务等专业的术语不能有硬伤

## 五、常见错误速查

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 角色OOC | 冷静的法医突然暴怒砸东西 | 如果必须这样，提供动机（如发现妻子出轨） |
| 时间悖论 | 白天发生的事，角色回忆成晚上 | 写日期记录表，每章开头标注时间 |
| 工具人出现 | 需要帮助时恰好出现一个"万事通" | 提前铺垫或让角色自己解决 |
| 逻辑跳跃 | 从"嫌疑人有车"跳到"他就是凶手" | 添加推理步骤：有车→可以到达现场→没有不在场证明→动机→确认 |
| 信息遗忘 | 最新手机却无法GPS定位 | 了解基础科技常识，或提前"破坏"这个功能 |
| 万能钥匙 | 什么锁都能开，什么系统都能破解 | 每个角色只能解决自己专业领域内的问题 |
