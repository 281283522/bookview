# 《玻璃裂隙》人物档案

---

## 主角

### 林深

| 维度 | 设定 |
|------|------|
| **性别/年龄** | 女，27岁 |
| **身份** | "原始人"——拒绝意识上传的现实世界居民 |
| **职业** | 前数据修复工程师，现废墟拾荒者 |
| **性格** | 表面冷淡、不信任何人，内心对姐姐的失踪有执念。话少，观察极细，习惯用指尖敲东西来思考。不擅长表达感情，但被触碰底线会爆发 |
| **核心驱动** | 找到失踪十年的姐姐林雪的真相 |
| **弱点** | 过度怀疑→错过信任机会；对"真实"有病态执着→无法接受灰色地带 |
| **弧线** | 从拒绝一切→被迫信任复制体→选择自我牺牲→在永恒的"不确定"中找到平静 |
| **关键物件** | 姐姐留下的全息日记片、捡到的海玻璃（蚀刻着自己名字） |
| **体貌特征** | 黑色短发、右手手腕有烧伤疤（姐姐失踪当天被大火烧伤）、常年穿深灰工装外套 |

## 核心人物

### 林雪（姐姐）

| 维度 | 设定 |
|------|------|
| **性别/年龄** | 女，失踪时24岁（现应34岁） |
| **身份** | 永生计划第3批志愿者 |
| **性格** | 阳光、执拗、天才级程序员。什么都敢试，什么都不怕。和林深截然相反，但两人互补 |
| **背景** | 2037年谎称去参加永生计划面试，实则是为了揭露计划的不法行为，主动应聘。在发现系统真相后试图从内部摧毁，被系统判定为"不稳定数据源"，冷冻于第3仓库24排9号 |
| **关键贡献** | 被冷冻前用最后意识权限生成了"海玻璃程序"——海玻璃由她的意识残片铸造，每一片都承载着她留下的一条线索 |
| **结局** | 罐子被打碎，意识状态未知 |

### "复制体林深"（刃的真正操控者/后来的修复员首领）

| 维度 | 设定 |
|------|------|
| **身份** | 林深上传那一刻，系统自动创建的备份——用于担任修复员。但因为复制了完整的林深意识，保留了部分人性 |
| **性格** | 比林深更冷。三年来亲手抹杀了上百个碎片者，已经不太确定自己还有没有感情。但见到林深来找林雪时，被触动了 |
| **关键台词** | "每次你觉得自己保持了记忆，那不是我漏掉的碎片。那是我留给你的。" |
| **转折** | 从追捕者变为合作者，最终帮助林深破解服务器 |

### 顾哲（碎片者首领）

| 维度 | 设定 |
|------|------|
| **身份** | 自称已在新伊甸存活三年的碎片者，组织其他碎片者对抗系统 |
| **真相** | 被系统擦除后，他是否真的是碎片者首领？还是他的所有信息都是系统植入给林深的假线索？ |
| **能力** | 善于操控信息、心理暗示 |

### 刃（修复员）

| 维度 | 设定 |
|------|------|
| **身份** | 年轻修复员，代号"刃"，负责处理碎片者 |
| **背景** | 一年前搭档被证实为"无编号上传者"后亲手击杀，此后开始偷偷帮助碎片者。每次见林深前自行注射短期记忆封锁剂——这样即使被审讯，他也不知道自己泄过密 |
| **核心秘密** | 搭档尸体上发现了海玻璃 |

## 系统设定

### 永生计划 / "新伊甸"

| 维度 | 设定 |
|------|------|
| **创立时间** | 2037年启动 |
| **公开目标** | 人类意识的数字化永生 |
| **真实目的** | 将所有上传者转化为"数据源"——每天提取记忆片段，为其他居民的"每日脚本"提供素材 |
| **关键技术** | 量子服务器集群 + 意识模拟AI |
| **核心谎言** | "每日记忆重置是为了优化体验"——实际上是为了让居民察觉不到自己的记忆在被抽取 |
