# 第81章 新条款

新约通过第二天，陈末在空白页写下的第一行，成了正式条款。

他把它拆成五条，发到黑单群，逐条解释。

第一条，原名"以送餐为名供给温度"，改为"以送餐为形，共享被记住的温度"。壳还是送餐，里子从供给变成共享。

第二条，恒跑封印作废。七位A级不再需要跑圈，裂隙时间层解除，第一代骑手挂回线上。

第三条，碎片陈直留于城内，作为网与城之连接。其安全由全城纪念集体维系，不再依赖单人锚点。

第四条，客服07保留人类身份，沈淑兰有权选择退出，其善意由后人自愿接续。

第五条，新增：凡点单者皆被记住，凡送餐者皆在陪。本系统自即日起由黑单转为纪念系统，任何骑手接单即自愿，系统不得用家庭困境作诱导。

第五条是陈末坚持加的。钱德胜看了，默默把补贴算法里"医疗支出触发"那条彻底删了。

"这条写进去，"陈末说，"以后不会有第二个我被八万手术费推进来。进来的人，是真心愿意陪的。"

老马泡了茶："何年要是看见第五条，该说'末娃比我狠'。我当年只敢写'不得强迫'，你直接把钩拆了。"

"不是狠。"陈末说，"是还债。第一代三十九人，有几个是被生活逼进来的？我母亲那八万，就是钩。我把钩拆了，算替他们松一道。"

阿蝉在第五条下面回了个"姑母同意"。沈淑兰的声音从07里传出来，很轻："第五条好。我当年进网，也是被何年一句'你愿意吗'请进来的。愿意和被迫，差一个字，差五十年。"

何小满把五条存进系统核心，替换了原初协议的前五条。替换的瞬间，泵站底下那台机器的绿膜亮了一瞬，呼吸和金港河潮水完全重合。

"新条款生效。"她说，"黑单系统，从现在起，叫纪念系统。"

陈末看着手机上"纪念系统"四个字，想起第1章那个黑色图标。五十年，它从陷阱的入口，变成了记忆的窗口。

"第一条写完了。"他对箱子里那枚缺笔的"相"说，"下面，是把'囚禁'这个词，从所有人嘴里拿掉。"

（第81章 完）
