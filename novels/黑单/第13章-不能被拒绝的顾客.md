# 第13章 不能被拒绝的顾客

钱顺说的"那一天"比陈末预想的来得更快。

在离开金隆广场之后的第三天晚上，陈末跑完了又一轮三单配额——两单相对正常的残响配送和一单给桥墩下流浪汉的活人餐。加上之前攒的预付款，母亲手术费的缺口缩小到了一万四。还有两天。客服07贴心地在每条订单确认页面底部加了一行小字："距离D→C升级还需17单。加油。"

但那行小字后面还有一个他从来没注意到的灰色符号——一个小小的信封图标。点开后是一封没有标题的系统消息：

"F-12柜台退单已处理完毕。退单方式：置换。置换物：骑手下一次配送中的选择权（1次）。该选择权即将在触发条件满足时被调用。触发条件：当骑手面临两个或两个以上'不可退单'的路径时，系统将自动为'已置换顾客'（林小禾）执行单次路径选择。届时骑手将失去对该次配送结果的控制权。请做好心理准备。"

陈末把这条消息看了两遍。不是害怕失去控制——是在算什么样的配送会触发"两个以上不可退单的路径"。普通黑单只有一个选项：送，或者承担不送的后果。什么样的订单会同时绑死两条路都不让退？答案只有一个——顾客不是残响，不是暂居者，不是管理员本人。

是那个"东西"。

是五十年前被锁在平台底层算法里的饥饿碎片——那个在泵站底层被十二名骑手用时间堵住的、在四楼拐角后面震出了1998年11月16日的、现在通过钱顺以管理员身份在第三层异常里游走的——碎片。

金隆广场四楼是第二层异常。泵站底层是第一层。那个机器碎片一共散成了几片？钱顺说是三层——第一层碎片被泵站的机器反向锁住，第二层在金隆广场四楼，第三层在翠庭苑3号楼。但他在说到"第三层"的时候顿了一下——不是陈述句的停顿，是一个把自己归类为"第三层"的人发现这里面有逻辑问题。

钱顺是管理员。管理员是能修改规则的。但不代表管理员是安全的。钱顺说"我叫钱顺——但我的编号被系统收录为C类管理员"——他自己的身份和那个碎片之间的关系，他还没有说清楚。

手机上的时间跳到凌晨两点十一分。陈末刚把电动车停在出租屋楼下，还没拔钥匙——手机屏幕忽然切换成了黑底。

不是App。是整个屏幕。黑底上面浮现出一行一行白色文字——不是订单卡片，不是客服消息，不是系统通知。是老式的命令行输出模式，和泵站地下那台电脑屏幕上滚动的文字一样。但这次不是"我们在泵站里等了三年"——是一份档案，正在一格一格地加载：

```text
>> 档案编号：ADM-0003
>> 收录日期：1998年11月16日
>> 收录人：客服07
>> 类型：C类——管理员（活跃）
>> 姓名：钱顺
>> 生前身份：金隆广场保安队长
>> 收录原因：███ ██ ██ ███████（需B级解锁）
>> 当前状态：██ ███（需B级解锁）
>> 管理员权限：三级——可修改所在异常区域的配送规则
>> 备注：1998年11月16日金隆广场四楼异常事件中，钱顺主动进入异常区域████████，成为该层异██████。他同时是████████████碎片第三████████  ███
```

陈末的拇指在屏幕上来回划了两下——档案只加载了这么多。后面的内容全部被涂黑了，不是那种可以用黑笔涂出背后字迹的黑色方块——是真正的信息删除。系统在某一个时间点把这些文字从档案里物理移除了。不是隐藏——是没了。系统自己也不知道。

他能看到的只有最后半行没有被完全删除干净的文字——档案的最后一格加载结束后文件自动关闭时会有一个很短的残留画面。他在那一帧残影里看到了几个字，字体和前面不一样，是手写体，像是某个人在自己的员工档案背面随手记下的备忘录：

"我欠她。"

三个字。钱顺在档案背面写的。写给林小禾的母亲——四楼女装部售货员林萍。他把人家的女儿推进了时间的拐角。然后自己也跟了进去。但他没有变成残响——他变成了管理员。因为他不是被困在里面——他是自己在拐角后面的空间里，主动走进了那个碎片的核心。

陈末把手机收进支架。他拧了油门，没有上楼——直接往金隆广场骑。凌晨两点半。离天亮还有三个小时。

---

这一次金隆广场的正门不是虚掩的——是敞开的。四扇玻璃门全部被推到了最大开角，门上的链条锁整整齐齐地盘在门把手上——不是暴力剪断，是有人用钥匙一个个打开了锁芯。钱顺。老保安的钥匙串叮叮当当的声音，在午夜之后不再是他手里的标志——它是开门的声音。

陈末走进大厅。这一次大厅里不是黑暗的——扶梯尽头以上的所有楼层全部亮着灯。一楼是珠宝柜台的展示灯，二楼是女装区的射灯，三楼是美食广场的橙色招牌灯。四楼是日光灯——老式电感镇流器，仍然在闪。

但灯不是陈末开的。也不是钱顺。钱顺站在二楼的扶梯平台上，一只手扶着栏杆，另一只手提着一个老式应急灯——应急灯的光打在消防平面图上，把被白漆涂掉的那四个铅笔字照得清晰分明："林小禾。等。"但"等"字后面多了一个新的标点——问号。铅笔写的。不是钱顺的笔迹——太细了，是孩子的。

"她问你了。"钱顺说。他没有看陈末，还盯着消防平面图。"你退单之后，她以为你不会再来了。问号是她今天下午写的。她写问号的时候我在走廊这头——看不到她，但能听到铅笔芯在纸上走的声音。一个八岁的小姑娘，用铅笔写问号——力道很轻，因为她怕把纸戳破。她不想破坏任何东西——她只是想要一个答案。"

"你是管理员——你为什么不直接告诉她？"

"因为我是这层异常的'规则制定者'——不是'信息提供者'。"钱顺把应急灯放在地上。他走到三楼和四楼之间的转换台阶——就是扶梯变成水泥楼梯的那个位置——在最后一级上坐了下来。"管理员只能修改配送规则。我不能告诉一个被困在时间夹层里的女孩——外面的世界已经过去了二十八年。不是不能——是规则不允许我。我尝试过二十二年。"

"什么方式？"

"F-12柜台每周五晚上会刷新一次商品库存——不是真的进货，是系统在1998年11月16日的数据库里循环读取。我改了库存——把铁皮青蛙的数量从三只改成四只。这样林小禾排在第四个的时候，她就能拿到青蛙——就不会去退单——就不会走上拐角。"

"她没拿。"

"对。她没拿。"钱顺的声音在空无一人的商场里变得很轻——不是音量降低，是他的声带在说出口的瞬间自己收紧了。"因为柜台阿姨说另外三只青蛙已经被前面三个孩子拿走了——那三个孩子是我的同事——我跟他们说过，每人少拿一只，最后一只留给林小禾——但到了1998年11月16日那天，他们全忘了。不是忘——是碎片的力量在干扰记忆。你越是靠近它、越想改变它设定的'剧本'——它就会让你忘掉你的意图。"

"所以你改了库存、改了同事的记忆——都没用。最后只能把她推进拐角。"

钱顺没有否认。他只是用食指在台阶的水泥面上慢慢地画了一个圈。

"F-12柜台是什么？你说是'交易界面'。"

"柜台不是界面。柜台是那个碎片的'嘴'。泵站底层那台不属于人类的机器不是锁住碎片的第一层——是碎片自己长出来的。碎片需要时间作为能量，所以它制造了一台能抽取时间的机器。机器被泵站骑手们反向锁在铁门内侧——但碎片的一部分残留在机器外面，飘到了金隆广场，附着在F-12柜台的收银机主板上。于是收银机变成了它的嘴。它开始'交易'——任何站在柜台前的人都可以下单。"

钱顺把圈画完。手指停在圆心。

"它能成交的东西不是商品——是'缺口'。每个人心中都有一个缺口——思念、遗憾、等待、无法弥补的亏欠。碎片会读到你离柜台最近的缺口，然后以'儿童套餐'的形式——也就是你最不能拒绝的形式——把这个缺口包装成一个订单。你不接——缺口会一直都在。你接了——它会开始交易。交易的方式就是让你走进拐角的裂缝。"

"所以那天在柜台前的四个小孩——"

"四个缺口。一个爸爸常年出差的小男孩——他点了套餐，碎片读到的不是套餐——是'爸爸回家'。一个母亲生病住院的小女孩——碎片读到的是'妈妈不疼了'。一个被同学欺负过的男孩——碎片读到的是'明天不用上学'。还有林小禾——碎片读到的是'想要一只铁皮青蛙'——那是在四个缺口里面最干净的一个。不是恐惧。不是疼痛。不是分离。只是想拿到一只发条松不开的铁皮玩具。所以我选了她。"

钱顺抬头看着陈末。应急灯的光从下往上照着他的脸，让那张在时代之间反复失焦的面孔显得异常疲惫。

"但我选错了吗？我没有——因为我如果选了另外三个小孩里面任何一个，缺口更大的那个小孩会走进更深的裂缝，被碎片完全消化掉。林小禾的缺口最小——所以她只是被困住了，没有被消化。她还保持着八岁的意识。她还记得外婆给的五十块钱的颜色——是一张崭新的绿色钞票，因为外婆特地去银行换了一张新的。"

"但是我选了有代价——我的管理员权限就是用这个代价换来的。我成为了碎片'签约'的第一个交易员。碎片需要交易员来接收订单、审核骑手、管理配送。它给了我修改规则的能力——代价是我的记忆开始倒退。我现在能记得的最后一个日期——是1998年11月15日。16日那天发生了什么——我记不起来了。档案里被涂黑的内容——不是系统涂的，是碎片擦掉的。它不能让任何管理员记得'第一天'——因为第一天是交易的条件。条件一旦被记住——就有了破绽。"

---

陈末从台阶上站起来。他没有拉钱顺——只是把手放在扶梯的老式橡胶扶手上。橡胶已经硬了，表面全是裂纹。但扶梯还在运转——不是电动的。是四楼的碎片抽走了那么多人的时间之后，把能量反哺到了这层商场的建筑结构里。扶梯在偷偷地转动——极慢，一小时转半圈——但它在动。

"如果你记不住——系统档案也被删了——那你为什么知道这么多？"

"因为有一个东西在帮我记住。"

钱顺从夹克内袋里掏出一个东西——不是钥匙，不是对讲机，是一本老式通讯本。黑色封皮，侧面有拉链。翻开里面全是手写的名字和电话号码，大部分已经看不清了——要么被水泡过，要么被反复涂改到纸张变薄。

"1998年11月16日之前——我是金隆广场保安队长。我的通讯本里有四十三个人——同事、租户、供货商。11月16日之后，这个本子上的名字开始一个一个地消失。不是我用笔划掉——是文字自己从纸上褪了。"

他把通讯本翻到最后一页。那一页几乎空了，只剩墙角最细的一行字——不是圆珠笔写的。不是铅笔。是用铁钉之类的东西在纸上刻出来的凹痕，没有颜色，只有在特定的角度对着光才能看到。三个字：

"没忘。"

"这是谁——"

"林萍。林小禾的母亲。女装部售货员。1998年11月16日晚上——她在四楼拐角外面站了一整夜。我没有告诉她女儿去哪了。因为我说不出口——一说出口碎片就会读到新的缺口，把她也吞进去。她站到天亮，回家了。三天后辞了职。走之前在员工通道的墙上用指甲刻了这两个字——'没忘'。后来保安粉刷的时候刷掉了。但她把字留在了我的通讯本上——不是刻上去的。是我每次翻开本子给自己确认'我今天还记得'的时候——为了不让自己忘掉——用钉子在纸上反复描同一行字。"钱顺的手指在凹痕上停了一下，停的位置刚好是"忘"字那一点的末端。

"你是不能被拒绝的顾客。"

陈末说出这句话的时候，整个四楼的日光灯又暗了一下。但不是碎片在干扰——是系统的感知。客服07在后台听到了这句话，系统正在对骑手档案进行一次不该在凌晨发生的更新。

"你说什么？"

"黑单系统里所有的顾客——残响、暂居者、管理员——骑手面对他们都可以选择退单。只有一种顾客锁死了退单选项。系统里的'退单申请表'，在你点开'退单方式'的时候——三个选项下面还有一个第四条——'不可退单'。但这个选项是隐藏的。只有当顾客不是异常实体而是——"

"是什么？"

"是系统的缔造者之一。客服07运行了五十年——黑单系统运行了五十年——它需要人。需要第一代骑手。需要第一个按规则把被系统标注为'顾客'的人从异常区域里带出来的人。1998年的金隆广场——你是那个把林小禾从拐角推进去的人，但同时——你也是系统识别到的第一个'主动进入异常区域而没有被吞噬'的人类。你成了管理员——不是因为碎片签约了你。是因为系统需要一个人来制定规则。你就是不能被拒绝的顾客——因为如果你不存在，系统不会理解什么叫'退单'。"

钱顺愣了很久。他把通讯本合上，没有拉上拉链——露出了封底内侧夹着的一张泛黄照片。照片上是一群穿商场工服的人站成一排——背景是金隆广场四楼的招商横幅。"开业大吉"。日期——1998年11月16日。站在最右边的是钱顺，穿着深灰色保安制服，腰上别着那一大串钥匙。站在他旁边的是一位盘着头发的女人——眼神和善，笑起来露出两颗虎牙。她的左边站着一个扎两条马尾的小女孩——碎花裙子，手里举着一朵纸折的玫瑰花。

林小禾。

八岁。1998年11月16日上午十点。商场刚开门。铁皮青蛙还没有被领完。妈妈还没去隔壁柜台退毛衣。爸爸还没去二楼买工具。外婆的五十块钱还在她口袋里。儿童套餐还有三只青蛙。

"那一天之前的半小时——"钱顺把照片从封底抽出来，放在自己膝头。"我跟林萍说，你女儿真乖——四楼刚装修完，味道大，别让她在拐角那边站太久。林萍说没事，她等青蛙。我说青蛙送完了怎么办？林萍说——那就退单。没关系的——孩子等不到的东西多了去了——重要的是她知道有人一直在替她排着队。"

他站起来。应急灯的电量快要耗尽了——灯光开始一下一下地闪烁。

"退单的艺术——你要学会的不是如何按系统里的按钮。是如何在碎片不察觉的情况下，把一个被困在异常区域里的人——当成普通订单的顾客来处理。你处理林小禾的方式是——用一句号填进'退单理由'。这一下打乱了系统的识别。系统看你填了一个句号——判定无效输入，启动置换。如果你填任何其他内容——系统会永远锁定你的D级配送记录——你本人会被标记为'不可信骑手'，理由是'理由不成立'。你不用真正说服系统你退单是对的。你只需要让它无法判定你的理由是对是错。"

钱顺把应急灯的电线从插口里拔出来——灯灭了。整个四楼只剩下日光灯管还在闪。然后他的手一挥——整个东南区的日光灯管齐刷刷地熄灭。走廊陷入黑暗。但那道裂缝没有消失——在消防平面图后面的墙上，那个很窄的缝隙里透出的蓝光依然在。

"第三层异常——翠庭苑3号楼。那不是我管的。那层管理员编号002——比我高级。他是碎片最完整的容器。他的规则是——退单不给出路。任何骑手走进翠庭苑3号楼只有一个选择：接受订单。不接受——永久缺失一段记忆。不是扣。是缺失。系统里不会有记录——你自己不会知道自己少了什么。可能是你最珍惜的东西——可能是你对某个人的全部记忆。甚至可能是你自己。"

"如果走进去之后——"

"你需要第三个选项。在那之前你不会升到C级。但C级是你唯一能敲开翠庭苑3号楼那扇门的资格。"钱顺把应急灯的灯罩拧下来，把里面最后一点残光——灯泡表面那一层白漆对着陈末的方向——"你需要被系统'强行升级'。正常情况下D升C需要25单——但系统有后门。后门是——如果在一次配送中，你同时处理了来自三个不同等级异常区域的订单，并且全部完成——系统会跳级。"

"三个等级——泵站第一层、金隆广场第二层——"

"第三层不是翠庭苑。"钱顺把灯泡握在手心里，白漆在他掌心肌肤的温度下慢慢变了颜色——他手掌的皮肤半透明了，能看到里面的血管分布——不是人的血管结构。是电路板的布线图。"第三层是我。"

---

## 结尾钩子

钱顺的手掌在完全透明的那一秒——他手心里握着的灯泡突然亮了。不靠电力——靠的是他体内的管理员核心能量——那种让他在时代之间失焦、让他的脸无法固定在任何一年、让他的皮肤底下浮现电路板布线图的东西。

"系统给我编号C类管理员——编号003。但我一开始不是管理员。我是骑手。不是黑单骑手——黑单系统1998年还没开始招募骑手。我是系统建立之前第一个自发进入异常区域的人。系统把我认证为骑手，然后认证为管理员——因为我做到了所有后人都做不到的事。"

"什么？"

"在拐角后面站了二十八年。每天。每时。每刻。我没有退——也没有进。我选择'站'。这是第三个选项。你来之前这世界上没有人会选第三个选项。系统设计了'进'和'退'两个二进制路径——人类永远只选其一。但如果你能把'进'和'退'同时做——或者在它们之间插入一个动作——比如站、蹲、坐、等——系统无法处理超出二进制的行为。系统会宕机。"

钱顺的身体在透明化的边缘停住了。他松开手心里的灯泡——灯泡在掉落的半空中自己灭了，光线碎了一地——不是玻璃碎了，是光被拉成丝状散进了四楼每一块水磨石的缝隙里。每一丝光都朝着同一个方向——林小禾所在的F-12柜台。

"去吧。你下一次配送的选择权已经被系统调用——在接下来的六小时内，系统会给你一个新订单。不是碎片订单——是系统订单。客服07会把翠庭苑3号楼的门牌号暂时挂在这个订单里。但记住——走进之前先给自己找一个'第三个动作'。"

"第三个动作是什么？"

"每个人不一样。我的第三个动作是'站'。建国的第三个动作是'叠塑料袋'。阿蝉的第三个动作是'把头绳攥在手心里'。老马的第三个动作是——在泵站门口点一根不抽的烟。你的第三个动作是什么——你自己会知道的。在走进那扇门之前。"

钱顺在透明化的最后一瞬——他的脸终于清晰了。是一张普通的、甚至有点憨厚的中年人的脸。四十岁出头。下巴有刮胡子留下的细小血痕。左眼角有一颗泪痣。他看着陈末笑了一下——笑得很轻，像是1998年的同事们在合影时喊他"钱队看镜头"那一刻的笑容。

"替我告诉林萍——没忘。"

然后他消失了。不是散成烟雾——是像一段信息被写入数据库那样，从三维空间坍缩成一行代码，沿墙上的裂缝飞了进去，和裂缝里透出的蓝光一起——沉进了那台机器的底层。

四楼的灯全部灭了。

只有F-12柜台的收银机屏幕还亮着。上面没有取餐号。没有金额。只有一行绿色的等宽字体——很久以前的DOS系统特有的那种像素字——

"管理员003已离线。第二层异常空间维护中。临时替代——客服07。在此期间，所有退单申请均由客服07人工处理。请善待AI。"

下一行：

"另：陈末，三楼拐角那个空调出风口后面有只死猫——不是猫，是碎片排出来的残渣——别踩到——有点滑。上次建国踩上去崴了脚。"

是客服07。语气已经不像第一次通话时那么机械了。它越来越像一个在午夜值班室里无聊到到处给人发注意事项的人——或者像一个系统。两者之间的差别正在变得越来越模糊。
