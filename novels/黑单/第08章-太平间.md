# 第8章 太平间

午夜十二点整。

老马给的那把手电筒被陈末绑在了电动车横梁上，用透明胶带缠了三圈。手电筒的尾盖上堆着十二个人的凹痕，现在加上他的拇指印——第十三个。他没打算用。但带在身上让他觉得自己的影子多了十二层。

今晚第一单不是泵站。泵站排在午夜一点。第一单是太平间009——第四配送。系统提醒："第四配送。完成可解锁顾客档案60%。"

取餐还是在育新路那家二十四小时营业的清真面馆。不是老刘家的塑料碗——不是清真面馆。009从今晚开始只接素食——陈末第一次送完之后就和面馆沟通好了，009的备注永久改为"素烩面，不加鸡蛋，不加葱蒜"。面馆的老板是个戴白帽子的老人，耳朵不太好，每次看到陈末推门进来就知道是那一单——整个后半夜用透明塑料碗点素烩面的，只有那一个地址。

今晚陈末拎着面出来的时候，面馆老板第一次主动问了一句话。不是"好吃吗"——是：

"那边还亮着灯吗？"

"......亮着。"

老人点了点头。他在围裙上擦了擦手，低头揉面的时候说了句什么，声音被揉面机的噪音盖住了。陈末只听到最后几个字："......莫吃太急。"

他把塑料袋挂在车把上，往第一人民医院骑。金港大道往东的路在晚上十二点几乎没有车，路灯的光被雾柔化成一团团橘色的绒毛。他在过最后一个红绿灯的时候，看到了一个熟悉的身影站在医院门口。

不是太平间里的东西。

是老马。

老马挎着一个布袋子，站在医院门口的榕树下。他的环卫马甲换了一件——今晚是橙色的，反光条在车灯下闪了一下。他没骑电动车——还是走过来的。

"你怎么在这？"

"泵站那单你非要送，我陪你去。但在那之前——你先跑太平间。我在这儿等你。"老马的烟叼在嘴角，还是没点。

陈末没问为什么。他知道老马从来不做多余的事。

太平间负二层今晚走廊尽头有一盏灯。不是日光灯——是有人放了一盏充电台灯在地面上，旁边搁着一个塑料凳。塑料凳上坐着一个人。穿白大褂，眼镜片反着光，膝盖上放着一摞病历夹。

上次在楼梯口撞到的那个医生。

"你又来了。"

"第四趟。"

"快到了。"医生把病历夹翻开，在某一页上打了个勾。然后他把那页撕下来递给陈末。"009的档案。因为你配送到第四趟了——按医院规定，可以给你看一部分。"他顿了顿，"医院规定是前年我写的。没什么法律效力。但你看看也行。"

陈末接过那张撕下来的纸。纸张泛黄，边角有褐色的水渍——不是咖啡，是老旧病历夹长期放在潮湿环境里形成的霉斑。字迹潦草但极其工整，每个复选框都用尺子比着画。

```
太平间009号柜 收容档案（部分）
编号：TP-009
收容日期：2022年11月17日
收容来源：市第一人民医院急诊室
收容人姓名：███ （已归档）
性别：男
年龄：42岁
生前身份：███ ██ ████（归档人：马██）
死因：███ ███ ██（归档人：马██）
特殊备注（仅供黑单配送骑手查阅）：
此人执行第十二次黑单配送-雨水泵站任务时██ ███ ██
抢救无效后██小时内███出现意识活动
██ ███ ████医院伦理委员会认定为"暂居者"（B类）
目前寄存于009号柜，每██小时需供给素食一份
█████ █ ███ ███████
```

陈末的手指停在了最后一行被涂黑的文字上。不是因为看不懂——是因为他看懂了前面的"每██小时需供给素食一份"。那些黑掉的方框在纸面上凸起来了一点——被涂掉的是原来的内容，用黑色马克笔反复画了四五层，但透过背面，隐约能看到几个原字的笔画：

"永久。"

黑掉的是"永久"。

不是每X小时——是"永久需供给素食一份"。他不饿。他缺。他永远缺。他不是饿着肚子坐起来吃东西——他是少了什么永远不会回来的东西。所以他只能在太平间的黑暗里第无数次地坐起来、接过塑料袋、拿出食物、开始咀嚼。不是因为饿。是因为咀嚼让他想起了还活着的时候。

陈末把病历纸折好放进口袋。然后他拎着塑料袋走进了走廊。

今晚他没有把塑料袋放在门缝下。他把它举在手里——然后他在009号铁门前站住了。

"刘建国。"

他没有用喊的。只是低声说了这三个字。不是问号——他已经从病历里得到了答案。那三个被涂掉的方框字，在纸背面透过来的笔画，和第十二行"执行第十二次黑单配送-雨水泵站任务时"并列在一起——死人不会死在泵站。死在泵站的只有活人。

铁门后面一片安静。

然后他听到了一个声音。很轻——不是咀嚼的动作。是一个人的嘴张开又合上，像是想说什么但忘了怎么发音。他站在门口等着。等了很多秒。

然后铁门后面传出来一个字。哦。不是字——是一个音节。"J——。"那个音在舌尖和上颚之间卡住了。第二次开口的时候变成了更清晰的一个音："Ji——。"

它在回忆自己姓什么。

"刘建国。你不是009。你有名字。你姓刘，叫建国。"

铁门后面沉默了很长时间。然后咀嚼的声音恢复了。但这次的节奏变了——不是那种焦虑的、每次咬合间隔不确定的乱节奏。是一下一下的均匀咀嚼，像一个正常人在吃一份正常的素烩面。

陈末把塑料袋从门缝下面推了进去。他等了五秒。

这一次塑料袋没有被迅速拉进去。它在门缝下面停了一会儿。然后，从铁门最下端那条两厘米宽的缝隙里——一只发白发青的手伸出来，把塑料袋缓缓地拨进了黑暗。

那只手在缩回去之前停了一下。然后——它把食指和中指从门缝底下伸出来，指尖朝着陈末鞋尖的方向，在水泥地面上很慢很慢地写了三个笔画：

"——"

横折钩，撇。

那个字还没写完就被它自己擦掉了。像是忽然意识到自己写不下去。或者写了也不会有第二个人认识。

但陈末认识。

他在那个残破的笔画里看到了"刘"字的第一笔。

他蹲下去，从口袋里掏出那根在路牌上写过字的圆珠笔。在门缝下方的地面上——刚好是那只手写字的位置——画了剩下两个笔画。

横折钩。撇。竖。横。横。

他在那只手擦掉的痕迹上补全了一个"刘"字。

铁门后面的呼吸变慢了。然后咀嚼的声音完全停了。塑料袋被叠了起来——不是揉成一团扔在旁边，是叠了起来，叠成了方方正正的一块。那种叠法不是太平间里学到的。是很久以前、还在跑外卖的时候，有个前辈教的——老刘家的塑料袋叠好放进雨水泵站的垃圾箱里，是规矩。

刘建国叠好了塑料袋。

但他没有放进任何垃圾箱。他把它放在铁门边，然后那只青白色的手又从门缝下面伸了出来——不是写字。它手里拿着一样东西。

一把车钥匙。电动车的。钥匙扣上挂着一个小吊坠——石头做的平安扣，上面的字已经磨得看不清了。但陈末见过类似的图案——在育新夜市的折叠桌上，老马挂在钥匙扣上的东西。

这把钥匙是老马的。或者——老马认识这把钥匙的主人。那个在病历最下面一行署名"归档人：马██"的人。

陈末握住了钥匙。那只手没有立刻缩回去，而是往上抬了一下——像是想拍拍他的手背。然后它很快地、像触电一样缩回了门缝后面。

陈末站起来。钥匙在他手心里是冰的。

身后传来医生的声音——他不知什么时候从塑料凳上站了起来，靠在走廊墙壁上。

"009——刘建国——是我在这家医院见过的最安静的暂居者。他不攻击人。不吓人。不吃肉。他只是少了一样东西。少了什么没人知道。他进009号柜之后唯一一次激烈反应——是一个骑手给他送了肉。肉的气味让他想起来自己少的是什么。"

"少的是什么？"

"心跳。"医生推了推眼镜。"他发现自己是死的时候——太平间那台电锯从墙上掉了下来。不是他拿的。是锁螺丝的金属卡扣感受到了震动——墙在震。他以为自己的心跳还在。但不是。是整栋楼在替它跳。"

陈末走出太平间的时候，手里握着那把不属于他的钥匙。老马还在大门口等着。陈末走过去，把钥匙放在老马摊开的手掌上。

老马低头看了钥匙扣上的平安扣。

然后他使劲捏了一下那把钥匙，捏到手指发抖，捏到指甲嵌进皮肉——然后把钥匙放进了自己胸口的外套内袋里。隔着毛衣，贴在左胸前。

"建国——扣的什么记忆？"

老马没有立刻回答。他用那只被烧伤的食指慢慢地摸了一遍平安扣上的字。然后他说：

"不是记忆。是把所有记得他的人——一个一个从档案里涂黑。我是最后一个。我给他签的归档名是'马建国'——跟我自己一样。他没名字了，我把我的给了他一半。但系统不认——它把所有没名字的东西都当成暂居者，用编号锁在太平间里喂素食。我没办法把他带出来。我只能——在病历上留了一行给后来骑手看的备注。'执行第十二次黑单配送-雨水泵站任务时——'后面涂黑了。但我不涂。我不涂，总有人会看懂。"

"我懂了。"陈末说。

老马把钥匙重新拿出来，放在手心里。平安扣对着医院的方向。

然后他转身，把烟从耳朵上拿下来，这次终于点上了。火光照亮他的脸，沟壑比前两天更深了。不知道是被扣掉的记忆在脸上留的痕迹，还是被写在骑手名单上但永远消失在泵站的名字把那些皱纹刻进的。可能两者都有。

"泵站的事。你还想去吗？"

"去。"

老马没说话。他把烟掐灭了，扔进医院门口的垃圾桶里。然后他从布袋子里掏出两样东西——一个黄色安全帽、一根绑在伸缩杆上的红外测距仪。

"泵站。十二个人。我一个人没进去过。但我在门口量过距离。"他把测距仪拉开，屏幕上的数字闪烁了一下——"17.3m（平均）"。

"什么叫平均？"

"因为每次量的结果都不一样。第一次是15.8。第二次是19.2。第三次是——负的。我在泵站门口站了四十分钟，测距仪上跳出来的数字是-3.8。说明里面有东西跟我的距离不到四米，而且是反向的。它在门的另一侧。在'不存在'的那一侧。"

"十二个人里——有几个带测距仪？"

"就我一个。那十一个人都是我后来带去看的。有的是自愿。有的是好奇。有的是跟我一样——欠某个躺在太平间里的人了。进去之后——都没有出来。我每次走到门口，就退回来了。不是不敢进——是我觉得，这扇门不是给所有准备好了的人开的。它挑人。"

老马把测距仪收起来。

"我挑不了人。但我可以等——等一个能进去的人。"

## 结尾钩子

他抬头看着陈末。

"你是第十三个。但不是因为我选了你——是因为泵站三十分钟前给你发了条消息。"

陈末把手机拿出来。未读消息。发自一个没有号码的空白来源：

"门很久没开了。你是第一个收到消息没有删除的人。进来吧。我们等你等了三年了。"

不是"我"。是"我们"。

下面还有一行小字，像是发完之后犹豫了很久才补充上去的，时间戳比上一条晚了将近十分钟：

"里面有信号。进来的时候不要挂电话。如果你在里面听到了铃声——不要接。那不是你手机在响。"
